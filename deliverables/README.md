Each scene contains `scene.mjz`, the program and Scene IR, semantic manifest,
provenance, checks and a 1024×1024 Cycles still under `render/`. Kitchen and warehouse
also contain articulated URDF packages and their recorded PyBullet verification.
Each mapping variant contains `mapping/data.h5`, `map.npz`, `map.png`, `rig.json`,
`report.json`, `rollout_scene.mjz` and `replay.mp4`. The data card explains the tiers.

The snapshot contains 2,165 copied files (4.72 GB decimal), plus these collection
reports. Files were copied, not moved or hard-linked. Original evidence is unchanged;
its JSON/logs and some historical links still name original workspace locations.
Use the relative links in this README/gallery to browse the collection.

The source includes uncommitted development at Git base
`d529b9fc20ecc3cf7bfb1c2e34e9b37d214e7d09`; it is not a claim that all artifacts were
generated by this exact revision. `code/docs/` preserves historical status notes;
this collection's checklist supersedes them for artifact inventory. Secrets, Git
metadata, environments, caches and vendor binaries are excluded. Bundled scenes
load without the vendor tree; setup fetches stock robots for new flows. Existing
asset provenance/licenses and robot licenses are included. The large local snapshot
is excluded from Git by its own `.gitignore`.

From the original repository, inspect the copied kitchen with:

```bash
.venv/bin/sim deliverables/outputs/deliverables_cleanup/kitchen/scene.mjz --viewer --backend glfw
```

To use the collected source on another machine, follow `code/docs/running.md`
and `code/README.md`. For example, from `deliverables/code` after installing the
documented system dependencies:

```bash
bash scripts/setup_pipeline.sh
# Requires an authenticated supported agent backend; creates a new output.
.venv/bin/pipeline generate --prompt 'A 60 square metre prep kitchen with four cabinets, two drawer units, two prep tables and a stocked shelf.' --seed 17 --output outputs/new_scene
.venv/bin/pipeline run outputs/new_scene --flow mapping --seconds 60 --output outputs/new_mapping
```

These commands document the existing interface; generation and cold setup were
not run as part of collection. No new scenes, simulations or paid calls were made.
